This hardened build compiles supported Luau into a per-build randomized register VM with polymorphic opcodes, encoded operands, junk instructions, shuffled constants/registers, randomized instruction layouts, integrity checks, and a large decoy surface. The original source is never embedded or reconstructed. Supported now: locals, assignment, globals, calls/method calls, tables, indexing, arithmetic/comparisons, and/or/not, if/elseif/else, while, repeat/until, numeric for, break/continue, and return. Unsupported syntax stops with an error instead of emitting broken code.
